# OM Telecom – Mobile Store & Digital Services

OM Telecom is a local **mobile store and digital service centre** in **Raghunathpur, Godda, Jharkhand**. The website is designed as a fast, responsive, professional static site that can be deployed directly on Render or GitHub Pages.
