# OM Telecom Gallery Images

Upload phone photos into this folder.

Then reference each photo in `indexGallery.html` using a relative path, for example:

`gallery/samsung-a56.jpg`

Use descriptive filenames in lowercase, such as:
- `samsung-a56.jpg`
- `redmi-note-15.jpg`
- `iphone-17.jpg`

Recommended: JPG or WebP images, compressed for fast loading.
